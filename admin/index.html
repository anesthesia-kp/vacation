FTE Availability
Set how much FTE is available each week. Every week shows its current value — change a number and save. These values are used everywhere: user bidding boards, the dashboard, draws & reviews, and outcome calculations.
🔐 Smart Lock Control — what it does
Smart Lock Control is the minimum remaining FTE a week needs to stay open. When Smart Lock runs (between phases, or from the dashboard), each week is compared to its own control value: remaining FTE below the control → the week locks (or stays locked); remaining FTE at or above the control → it unlocks (or stays unlocked). Range −1.0 to +1.0 in 0.1 steps; every week starts at 0.4.
Examples: control 0.4, week has 0.3 remaining → locks. Control 0.4, week has 0.4 remaining → stays open. Control −0.2, week has −0.1 remaining → stays open (−0.1 is above −0.2).
How to use it: leave everything at 0.4 and Smart Lock handles the whole year automatically between phases. Lower a week's control (even negative) to keep that week biddable deeper into overage; raise it to close a week off earlier.

Controls
Global schedule settings.
Update Username Prompt
Prompt users to update their username
When ON, users are offered a chance to set a custom display name (username) when they sign in. When OFF, users just sign in with their initials and are not prompted. Any username a user picks is visible to admin in the Users list.
Email Prompt on Login
Email Prompt on Login
When ON, users are asked to enter their email when they sign in. When OFF, the prompt is skipped.
Require Passwords
Require Passwords
When ON, users must set and enter a password to sign in. When OFF, anyone can sign in without a password.
Priority Lock
Priority Lock (bids only increase)
When ON, users can only upgrade their bid priority, never downgrade. When OFF, users can freely change to any priority.
Email Notifications on Change
Email Notifications on Change
When ON, users receive emails when their bid outcome changes. When OFF, no emails are sent.
NP Bids by Phase
Allow or block NP (no-preference) bids per phase. Users may only place NP bids during phases toggled ON. Changing a toggle affects NEW bids only — existing NP bids stay as placed.
Max Bids for Current Phase
Bids allowed per user, for the current phase
Applies to the current phase only — each user may place up to this many new bids in the phase now underway. Bids from completed phases don't count against the limit (they're locked and can't be changed anyway). Whole numbers 1–10, or tick "No limit" — with no limit, users are bounded only by the bid numbers they have available (1,2,3 · 1,2 · 1–10 · NP). Editing or removing an existing bid is always allowed.
FTE Overage Amount
Maximum FTE Overage
Shapes PROJECTIONS during bidding: how far over capacity a bid can be and still become a DRAW (each tied user must fit within this amount) or UNDER REVIEW (single user over cap by this amount) instead of an automatic loss. Range 0.0–2.0, step 0.1. Default 0.5.
It no longer affects week locking — Smart Lock uses each week's Smart Lock Control (set in FTE Availability) instead.
Only editable when zero bids are placed — locked once bidding is live.
Outbid Alert Queue
Outbid Alert Queue: 0 pending
Alerts are saved to a queue the moment a bid changes, then emailed. If the sender's browser closes first, ANY open page (user or admin) delivers them within about a minute using a claim system that prevents duplicates. The button flushes immediately from here.
